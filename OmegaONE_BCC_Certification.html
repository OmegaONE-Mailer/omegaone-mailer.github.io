OmegaONE Mailer — BCC Distribution Certification

Direct browser OAuth + Gmail API. No backend. This test sends a real HTML attachment. BCC recipients will be visible to you in Sent mail, but should not be visible to one another. For a meaningful privacy test, use two separate recipient mailboxes you control.

Settings are saved only in this browser's local storage on this site. Never put customer lists or access tokens in the public GitHub repository. This test requires 2 BCC addresses, different from the sender and each other.

Gmail's overall message size limit applies; MIME/Base64 increases the transmitted size.
